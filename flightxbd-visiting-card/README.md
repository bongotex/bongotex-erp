## How to print

1. Open `index.html` in Chrome or Edge.
2. Click **Print / Save as PDF** (or use the browser print dialog).
3. Use landscape/portrait as needed; enable background graphics for the pearl fill.
4. Replace the QR placeholder on the back with a live code pointing to `https://www.flightxbd.com` before final print production.

For commercial print, export the HTML sides to PDF/PNG and match the die-cut wavy edge + circular punch from the reference cards.
